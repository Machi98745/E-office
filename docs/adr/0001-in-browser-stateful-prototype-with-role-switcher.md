# Stateful Prototype with Role Switcher and 1-Click Role Login

Status: Superseded in persistence details by ADR-0002

To demonstrate multi-role E-Office approval flows (Requester, Clerk, Approver) during academic presentations on a single machine, the application provides both an instant Role Switcher in the top navigation bar and a 1-Click Role Login screen. This allows a single presenter to submit a Memo or Leave Request and immediately switch perspectives to register a Document Number, return for revision, or apply an Electronic Signature in real time.
