# In-Browser Stateful Prototype with Role Switcher

To demonstrate multi-role E-Office approval flows (Requester, Clerk, Approver) during academic presentations without requiring multi-account login or external database setup, the system uses an in-browser state store persisted in `localStorage` paired with an instant Role Switcher in the top navigation bar. This allows a single presenter to submit a Memo or Leave Request and immediately switch perspectives to register, return, or approve it in real time, with a one-click reset to restore seed data.
